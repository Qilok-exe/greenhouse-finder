# Integrating agents/ output into app.html

For Person B. Person A does not edit `app.html`, so the three pieces below are ready to paste. Paths assume `app.html` sits at the repository root.

## 1. The output div

Place it where the grant draft should appear. The agents code renders only inside this element.

```html
<div id="agent-output"></div>
```

## 2. The script tags

Paste these just before `</body>`, in this order. They are classic scripts: do not add `type="module"`, because module scripts fail when the page is opened from `file://`.

```html
<script src="agents/format.js"></script>
<script src="agents/check_numbers.js"></script>
<script src="agents/grant_writer.js"></script>
<script src="agents/cache/manifest.js"></script>
<script src="agents/browser.js"></script>
```

## 3. The render call

Call this wherever a greenhouse is selected, passing the record in the shape from `data/record-shape.md`:

```js
if (window.AgentView) AgentView.render(record);
```

Call it again each time the selection changes. Each call clears and redraws `#agent-output`.

## What render does and does not do

- It reads the cached templates from `agents/cache/manifest.js` (`window.AGENT_CACHE`). It makes no network call and never calls the model.
- It creates and changes elements only inside `#agent-output`.
- It does not modify the record object and writes nothing to `data/`.
- It needs `evidence.quote_uploaded` to be `true` or `false`. While it is `false`, the draft starts with "application draft: quote missing".
- It uses `fixes`, `estimate`, `evidence` and `price_per_gal` from the record. If a value a template needs is missing, the div shows an error instead of a draft with a wrong number.
- The "Match is cash" and "Nothing bought yet" checkboxes inside the div are kept in agents/ state, not in the record.

## Before it works

- `agents/cache/manifest.js` is generated by Person A with `node agents/precompute.js`. Until it exists, the browser reports a failed script load for that file and the div shows an error.
- The records in `data/greenhouses_hampshire.json` do not have `fixes`, `estimate` or `evidence` yet. The draft needs them.
